# Changelog

## 1.0.0

Primeira versão pública.

- Auditoria local, somente leitura, de UX, UI, acessibilidade e responsividade.
- Relatório HTML autônomo com visual GNZ, impressão A4 e botão Salvar como PDF.
- Gerador opcional `scripts/build_report.mjs` (Node.js 18+, sem dependências).
- Compatível com Claude Code (`/interface-audit`) e Codex (`$interface-audit`).
- Instruções de instalação para Windows, macOS e Linux.
- Exemplos fictícios em `examples/`.
- Licença de uso gratuita, não open source, em `LICENSE.md`.
